# BNBX 基金会份额名册设计

## 目标

在 BNBX 网站新增一个易发现、可公开查看的基金会入口与静态份额名册。页面只展示已确认的编号、名称、份数和对应 BNBX 数量，不公开个人钱包地址，也不展示市值释放节点或释放规则。

## 页面与入口

- 新增 `/foundation` 页面。
- 全站左侧固定一个金色盾牌式 `BNBX基金会` 入口，与右侧 X-One 悬浮入口错开。
- 桌面端显示盾牌与完整名称；移动端保持可点击尺寸，并缩短为紧凑入口，不能遮挡主要操作。
- 页面遵循现有黑白主题和中文、英文、韩文、日文语言状态。

## 总览信息

- 每份：1,000,000 BNBX。
- 总份数：500份，即500,000,000 BNBX。
- 当前登记：32份，即32,000,000 BNBX。
- 剩余：468份，即468,000,000 BNBX。
- 登记进度：6.4%。
- 五签三多签地址：`0x3485534a9b3a2630febe0708d82d94a63fe9d8bd`。
- 多签地址提供复制与 BscScan 查看操作；不调用 RPC。

## 名册

- 保持社区成员原始编号 `001` 至 `021` 的顺序。
- `002 霏霏老师`登记2份；其余20位社区成员各登记1份。
- `022 BNBX平台方`登记10份。
- 桌面端用四列表格展示：编号、股东名称、份数、BNBX数量。
- 移动端使用逐行卡片布局，确保长名称完整可读。
- 不展示个人股东钱包地址，不提供个人地址搜索。

## 数据与边界

- 名册使用版本控制内的只读静态数据，不接数据库、钱包或区块链节点。
- 页面明确说明这是基金会份额登记公示，不构成收益承诺。
- 后续增补必须通过代码变更追加并保留 Git 历史，避免静默修改。
- 本次只交付 Preview，不合并 `main`，不发布正式站。

- 汇总值由名册数据计算，登记32份、剩余468份、进度6.4%。
- 页面不存在个人钱包地址列或释放规则文案。
- 多签地址准确且 BscScan 链接正确。
- 桌面端和移动端均可访问；主题与四种语言可用。
- 测试、ESLint、TypeScript 与生产构建通过后才发布 Preview。
